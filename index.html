1. เซตและตรรกศาสตร์ ▾

• เซต: การดำเนินการยูเนียน อินเตอร์เซกชัน และสูตรจำนวนสมาชิก:

$$n(A \cup B) = n(A) + n(B) - n(A \cap B)$$

• ตรรกศาสตร์: ประพจน์ ตัวเชื่อม $(\land, \lor, \rightarrow, \leftrightarrow)$ และสมมูลที่สำคัญ $(p \rightarrow q \equiv \sim p \lor q)$

2. จำนวนจริงและพหุนาม ▾

• ทฤษฎีบทเศษเหลือและการแก้อสมการพหุนามตัวแปรเดียว:

$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

• ค่าสัมบูรณ์: $|x| \le a \iff -a \le x \le a$

3. ฟังก์ชันและเรขาคณิตวิเคราะห์ ▾

• ระยะห่างระหว่างจุด ความชัน และสมการวงกลม/พาราโบลา/วงรี/ไฮเพอร์โบลา:

$$d = \frac{|Ax_1 + By_1 + C|}{\sqrt{A^2 + B^2}} \quad,\quad (x-h)^2 + (y-k)^2 = r^2$$
ชั้นมัธยมศึกษาปีที่ 5
4. ตรีโกณมิติและฟังก์ชันเอกซ์โพเนนเชียล ▾

• เอกลักษณ์ตรีโกณมิติและกฎของไซน์/โคไซน์:

$$\sin^2\theta + \cos^2\theta = 1 \quad,\quad c^2 = a^2 + b^2 - 2ab\cos C$$

• สมบัติลอการิทึม: $\log_a(xy) = \log_a x + \log_a y$

5. เวกเตอร์ จำนวนเชิงซ้อน และความน่าจะเป็น ▾

• ผลคูณเชิงสเกลาร์ (Dot product) และหลักการนับ/การจัดหมู่:

$$\vec{u}\cdot\vec{v} = |\vec{u}||\vec{v}|\cos\theta \quad,\quad P(E) = \frac{n(E)}{n(S)} \quad,\quad \binom{n}{r} = \frac{n!}{r!(n-r)!}$$
ชั้นมัธยมศึกษาปีที่ 6
6. ลำดับ อนุกรม และแคลคูลัสเบื้องต้น ▾

• อนุกรมเรขาคณิตและอนุพันธ์/ปริพันธ์ของฟังก์ชัน:

$$S_\infty = \frac{a_1}{1-r} \quad,\quad \frac{d}{dx}[x^n] = nx^{n-1} \quad,\quad \int x^n dx = \frac{x^{n+1}}{n+1} + C$$
7. สถิติศาสตร์และการแจกแจงความน่าจะเป็น ▾

• ค่ากลาง การกระจาย และค่ามาตรฐาน ($z$-score):

$$\bar{x} = \frac{\sum x_i}{N} \quad,\quad s = \sqrt{\frac{\sum(x_i-\bar{x})^2}{N-1}} \quad,\quad z = \frac{x - \mu}{\sigma}$$
⚛️ ฟิสิกส์ ม.ปลาย
ชั้นมัธยมศึกษาปีที่ 4 (กลศาสตร์ 1)
1. การเคลื่อนที่แนวตรงและกฎนิวตัน ▾

• 5 สมการการเคลื่อนที่แนวตรงความเร่งคงที่:

$$v = u + at \quad,\quad s = ut + \frac{1}{2}at^2 \quad,\quad v^2 = u^2 + 2as$$

• กฎข้อ 2 ของนิวตันและแรงเสียดทาน: $\Sigma \vec{F} = m\vec{a} \quad,\quad f = \mu N$

2. สมดุลกล งาน-พลังงาน และโมเมนตัม ▾

• สมดุลต่อการหมุนและกฎการอนุรักษ์พลังงานกล/โมเมนตัม:

$$\Sigma M = 0 \quad,\quad E_1 + W = E_2 \quad,\quad \Sigma \vec{p}_{\text{ก่อน}} = \Sigma \vec{p}_{\text{หลัง}}$$
ชั้นมัธยมศึกษาปีที่ 5 (คลื่น แสง เสียง ไฟฟ้า)
3. คลื่นกล แสง และเสียง ▾

• อัตราเร็วคลื่น การหักเห (Snell's Law) และความเข้มเสียง:

$$v = f\lambda \quad,\quad \frac{\sin\theta_1}{\sin\theta_2} = \frac{n_2}{n_1} = \frac{v_1}{v_2} \quad,\quad \beta = 10\log\left(\frac{I}{I_0}\right)$$
4. ไฟฟ้าสถิตและไฟฟ้ากระแสตรง ▾

• กฎของคูลอมบ์และกฎของโอห์มในวงจรไฟฟ้า:

$$F = \frac{k|q_1q_2|}{r^2} \quad,\quad V = IR \quad,\quad P = IV = I^2R = \frac{V^2}{R}$$
ชั้นมัธยมศึกษาปีที่ 6 (ความร้อน ของไหล อะตอมและนิวเคลียร์)
5. แม่เหล็กไฟฟ้า แก๊ส และของไหล ▾

• แรงแม่เหล็ก กฎแก๊สอุดมคติ และสมการแบร์นูลลี:

$$F = qvB\sin\theta \quad,\quad PV = nRT \quad,\quad P_1 + \frac{1}{2}\rho v_1^2 + \rho gh_1 = \text{คงที่}$$
6. ฟิสิกส์อะตอมและฟิสิกส์นิวเคลียร์ ▾

• ปรากฏการณ์โฟโตอิเล็กทริกและครึ่งชีวิต:

$$hf = W + E_{k,\max} \quad,\quad N(t) = N_0 \left(\frac{1}{2}\right)^{t/T_{1/2}} \quad,\quad E = mc^2$$
🧪 เคมี ม.ปลาย
ชั้นมัธยมศึกษาปีที่ 4
1. โครงสร้างอะตอม ตารางธาตุ และพันธะเคมี ▾

• การจัดเรียงอิเล็กตรอนและแนวโน้มตารางธาตุ ($IE, EA, EN$):

$$1s^2 \ 2s^2 \ 2p^6 \ 3s^2 \ 3p^6 \ 4s^2 \ 3d^{10} \dots$$

• พันธะไอออนิก โคเวเลนต์ (VSEPR รูปร่างโมเลกุล) และพันธะโลหะ

2. โมล สารละลาย และปริมาณสารสัมพันธ์ ▾

• ความสัมพันธ์ของโมลและการเตรียมสารละลาย:

$$\text{mol} = \frac{g}{M_w} = \frac{N}{6.02 \times 10^{23}} = \frac{V_{\text{STP}}}{22.4} = \frac{CV}{1000} \quad,\quad C_1V_1 = C_2V_2$$
ชั้นมัธยมศึกษาปีที่ 5
3. แก๊ส อัตราการเกิดปฏิกิริยา และสมดุลเคมี ▾

• กฎของแก๊สและค่าคงที่สมดุล ($K_c, K_p$):

$$PV = nRT \quad,\quad aA + bB \rightleftharpoons cC + dD \implies K = \frac{[C]^c[D]^d}{[A]^a[B]^b}$$

• หลักของเลอชาเตอลิเยร์ (Le Chatelier's Principle)

4. กรด-เบส และเกลือ ▾

• การแตกตัวของกรด-เบส ค่า $pH$ และการไทเทรต:

$$pH = -\log[H_3O^+] \quad,\quad [H_3O^+] = \sqrt{K_a C_a} \quad,\quad aC_aV_a = bC_bV_b$$
ชั้นมัธยมศึกษาปีที่ 6
5. เคมีไฟฟ้า (Electrochemistry) ▾

• ปฏิกิริยารีดอกซ์ เซลล์กัลวานิก และเซลล์อิเล็กโทรไลต์:

$$E^\circ_{\text{cell}} = E^\circ_{\text{cathode}} - E^\circ_{\text{anode}}$$
6. เคมีอินทรีย์และพอลิเมอร์ ▾

• หมู่ฟังก์ชัน (Functional Groups): แอลกอฮอล์, แอลดีไฮด์, คีโตน, กรดคาร์บอกซิลิก, เอสเทอร์, เอไมด์

• ปฏิกิริยาเอสเทอริฟิเคชัน และการเกิดพอลิเมอร์ (Addition / Condensation)

1. เซลล์ ออร์แกเนลล์ และการลำเลียงสาร ▾

• โครงสร้างเซลล์: นิวเคลียส, ไมโทคอนเดรีย (สร้าง ATP), คลอโรพลาสต์, ไรโบโซม, ER

• การลำเลียงสาร: Passive Transport (Diffusion, Osmosis, Facilitated) และ Active Transport

2. การหายใจระดับเซลล์และการแบ่งเซลล์ ▾

• Cellular Respiration: ไกลโคลิซิส $\rightarrow$ สร้าง Acetyl CoA $\rightarrow$ วัฏจักรเครบส์ $\rightarrow$ การถ่ายทอดอิเล็กตรอน (ได้ 30-32 ATP)

• การแบ่งเซลล์: ไมโทซิส ($2n \rightarrow 2n$) vs ไมโอซิส ($2n \rightarrow n$ เกิด Crossing over ใน Prophase I)

ชั้นมัธยมศึกษาปีที่ 5
3. สรีรวิทยาของพืชและการสังเคราะห์ด้วยแสง ▾

• Photosynthesis: Light reaction (ไทลาคอยด์ ได้ ATP, NADPH) และ Calvin cycle (สโตรมา ตรึง $\text{CO}_2$)

• การลำเลียงน้ำ (Xylem - แรงดึงจากการคายน้ำ) และอาหาร (Phloem - แรงดันชลศาสตร์)

4. ระบบร่างกายมนุษย์ (สรีรวิทยาสัตว์) ▾

• ระบบย่อยอาหาร, ระบบหมุนเวียนเลือดและภูมิคุ้มกัน, ระบบหายใจ, ระบบขับถ่าย (เนฟรอน), ระบบประสาท (Action potential) และต่อมไร้ท่อ (ฮอร์โมน)

ชั้นมัธยมศึกษาปีที่ 6
5. พันธุศาสตร์ โมเลกุล และเทคโนโลยี DNA ▾

• กฎของเมนเดล และ Central Dogma:

$$\text{DNA} \xrightarrow{\text{Transcription}} \text{mRNA} \xrightarrow{\text{Translation}} \text{Protein}$$

• พันธุวิศวกรรม: การตัดต่อยีน, PCR, Gel electrophoresis

6. วิวัฒนาการและนิเวศวิทยา ▾

• กฎของฮาร์ดี-ไวน์เบิร์ก (Hardy-Weinberg Equilibrium):

$$p + q = 1 \quad,\quad p^2 + 2pq + q^2 = 1$$

• ความหลากหลายทางชีวภาพ ไบโอม และวัฏจักรสารอาหารในระบบนิเวศ
